# 해담 — 부산 해양 안전 웹앱

부산의 7개 주요 해수욕장을 위한 모바일 중심 해양 안전 서비스입니다. 이안류, 최근 해파리 출현 추세, 현재 파고와 서핑 지수를 한 화면에서 확인할 수 있습니다.

## 주요 기능

- React Leaflet과 OpenStreetMap 기반 부산 해안 지도
- 해운대·광안리·송정·송도·다대포·일광·임랑 해수욕장 정보
- 클릭 가능한 해수욕장 마커와 단일 반투명 위험 원
- 홈, 위험도 순위, 상세 정보, 설정 화면
- 즐겨찾기, 다크 모드, 한국어/영어, 지도 레이어, 서핑 숙련도, 자동갱신
- LocalStorage 기반 개인 설정 유지

## 실행

```bash
pnpm install
pnpm dev
```

배포용 빌드:

```bash
pnpm build
```

현재 데이터는 `src/services/marineDataService.js`에서 관리하며, API 연결 시 이 모듈만 교체할 수 있도록 UI와 분리되어 있습니다.
